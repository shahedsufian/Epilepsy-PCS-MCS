# Influence of insurance coverage on health status among epilepsy patients in the US
**Shahed Md Abu Sufian, MPH**

This project evaluates the effect of insurance coverage on health status among epilepsy patients in the US. It uses a retrospective cross-sectional design, linking secondary data from the 2014-2019 Medical Expenditure Panel Survey (MEPS) full-year consolidated datasets with the 2014-2019 MEPS medical conditions datasets. This study includes civilian, non-institutionalized U.S. individuals with epilepsy. Physical Component Summary (PCS) and Mental Component Summary (MCS) were used as the outcome measures of health status. They were derived from the SF-12 questionnaire, which measures an individual's overall health status by calculating separate scores for physical and mental wellbeing based on their responses to a set of questions in the MEPS. I used Generalized Linear Models to assess the influence of insurance coverage on health status among epilepsy patients in the US. Additionally, I described the socio-demographic characteristics of the epilepsy patients.

## Usage
To run the code, you will need R installed on your machine. Follow the steps below:
1. Clone the repository: `git clone https://github.com/yourusername/SS-Epilepsy-PCS-MCS.git`
2. Navigate to the `ProgramScript` folder and open the R code file.
3. Run the code in R after collecting the required datasets.
